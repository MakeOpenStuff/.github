## 📦 Legacy: HestiaPi (5 most recently updated)

Earlier HestiaPi projects remain in the original [HestiaPi](https://github.com/HestiaPi) organization (kept in place to avoid breaking existing links):

- [hestia-touch-openhab](https://github.com/HestiaPi/hestia-touch-openhab) — OpenHAB2 files for HestiaPi Touch
- [hestia-touch-pcb-dev](https://github.com/HestiaPi/hestia-touch-pcb-dev) — PCB files (dev/testing releases)
- [hestia-touch-one-ui](https://github.com/HestiaPi/hestia-touch-one-ui) — ONE UI for the touch LCD
- [hestia-touch-case](https://github.com/HestiaPi/hestia-touch-case) — 3D printable case
- [hestia-touch-toolkit](https://github.com/HestiaPi/hestia-touch-toolkit) — manufacturing/testing tools

See [all HestiaPi repositories](https://github.com/orgs/HestiaPi/repositories) for the full list.
